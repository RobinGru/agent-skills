# Accessibility baseline

Target WCAG 2.2 AA where product requirements do not specify stricter level.
Use semantic controls before ARIA. Verify accessible names, roles, values, and
state changes for affected interactions.

Check visible focus, keyboard order, contrast for essential content, pointer
target usability, reflow at narrow widths, and text scaling to 200 percent
where applicable. Respect reduced-motion preferences. Use W3C WCAG resources
for normative criteria; this guide is an implementation checklist.

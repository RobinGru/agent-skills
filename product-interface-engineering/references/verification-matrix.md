# Verification matrix

| Status | Meaning |
| --- | --- |
| Passed | Check ran and met criterion. |
| Failed | Check ran and did not meet criterion. |
| Not run | Check unavailable, blocked, or out of scope; state why. |
| Not applicable | Criterion does not apply; explain when unclear. |

For local scope, verify affected behavior and nearest layout or input boundary.
For flow scope, include relevant states, keyboard operation, focus, and
recovery. For systemic scope, add cross-screen consistency, supported platform
coverage, localization concerns, and performance risk assessment.
